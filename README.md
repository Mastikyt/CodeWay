# CodeWay — адаптация проекта на Vue.js

Проект CodeWay построен на **Vue 3** и **Vite**. В проекте есть основное приложение и отдельная витрина заданий Tailwind CSS.

## Быстрый запуск

```bash
npm install
npm run api     # демонстрационный API на localhost:3001, если нужен локально
npm run dev     # Vite на http://localhost:5173
```

Frontend в режиме разработки проксирует `/api` на `http://localhost:3001`. API запускается отдельно через `npm run api`. Порт dev-сервера зафиксирован (`strictPort: true`): если `5173` занят, Vite завершится с ошибкой, а не переедет молча на `5174`.

## Настройка адреса API

Адрес backend задаётся переменной окружения `VITE_API_URL` (см. `.env.example`); скопируйте пример в `.env.local` и укажите свой API:

```bash
cp .env.example .env.local
# VITE_API_URL=https://api.example.com
```

Без переменной в разработке используется `http://localhost:3001`, а в собранной версии — тот же origin, что и у сайта. На статическом хостинге backend отсутствует, поэтому запросы к API не проходят и приложение работает через демонстрационный `localStorage` fallback.

## Вход в систему

Страница входа — `/login` (регистрация — `/register`, восстановление пароля — `/forgot-password`).

| Роль | Email | Пароль |
|---|---|---|
| Администратор | `admin@codeway.by` | `admin123` |
| Студент | `user@codeway.by` | `user123` |

Демонстрационные учётные записи создаются автоматически: сервер хранит их в `db.json`, а при недоступном API — в `localStorage` браузера. На странице входа есть кнопки быстрого входа, а после авторизации открываются `/data`, для администратора дополнительно `/admin`.

## Сборка и статический хостинг

Сборка для публикации выполняется командой `npm run build`; каталог результата — `dist`. Настройте хостинг с командой сборки `npm run build` и output directory `dist`. Для деплоя через Git-интеграцию проект необходимо поместить в репозиторий и подключить его к выбранному провайдеру. Для Cloudflare Pages в `public/_redirects` настроены `/` и Tailwind-витрина `/tailwind` с поддержкой вложенных маршрутов.

Статический хостинг раздаёт собранные файлы и **не запускает локальный `localhost:3001` как удалённый production API**. В приложении есть демонстрационный fallback на `localStorage`; он хранит данные только в браузере и не является общей базой данных, backend или production-системой авторизации. Для реальной публикации функций, требующих API, нужен отдельно развёрнутый сервер или серверные функции.

Отчёт о вариантах размещения: [`docs/hosting-platforms-comparison.md`](docs/hosting-platforms-comparison.md). Тарифы, квоты и политики хостингов могут меняться — проверяйте официальные источники перед запуском.

## Структура страниц

- `/` — основное приложение CodeWay.
- `/tasks` — задания Tailwind внутри основного приложения.
- `/tailwind` и `/tailwind/level-1` … `/tailwind/level-4` — отдельная витрина заданий.
